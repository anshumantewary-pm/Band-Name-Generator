# Band Name Generator

A beginner Python console program that builds a band name from three answers: your name, your place of birth and your pet's name. Written as an early exercise in taking user input and joining strings.

## Features

- Three interactive prompts in the terminal
- Joins the answers into one band name, for example `AshaPuneBruno!`

## Tech stack

- Python 3 (standard library only, no dependencies)

## Getting started

Prerequisites: Python 3 installed.

```bash
git clone https://github.com/anshumantewary-pm/Band-Name-Generator.git
cd Band-Name-Generator
python "Band Name Generator.py"
```

Example session:

```text
Welcome to our own band name generator program
What is your name? Asha
Please enter the place of birth? Pune
What is the name of your pet? Bruno
The band name is AshaPuneBruno!
```
